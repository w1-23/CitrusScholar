# 数据审查：Code 优先，结果可复核

## 输入与结构
先复用同一文件版本的已保存结构和数据结果。没有可用结果时，通过 Code 读取原件，识别工作表、多个数据块、表头、实际原始行列和覆盖范围。预览窗口不代表整张表；部分读取不能据此断言后面没有数据。

原件只读。保留源文件身份/哈希和原始位置；不要擅自补值、删点、改变原序或覆盖输入。公式与缓存值分开记录，不能把格式当成原始测量精度。

## 检查
按用户目标与实际结构，批量完成缺失、类型、重复、显式范围和适用的数值关系检查。可以调用 citrus_audit 已有函数，也可以写更合适的少量代码；不要求原生审查工具先失败，不要求运行全部规则。

从列名推断的分组要标为推断。独立生物学重复、单位、归一化方式和统计口径不能凭命名确证。可先完成不依赖这些语义的检查；仅在关键未知会改变结论时询问。

对高价值命中核对原值和坐标，合并同一问题的重复报警。数学全等、恒差可确证；复制方向、数据修改动机或科研不端不能仅由这些关系认定。

## 输出与复用
报告优先展示：已证实的数值关系/显式规则违反、需溯源疑点、一般观察；另给实际覆盖及未检查项。不要默认逐格刷屏。原值和完整命中保存在机器可读结果中，按需展开。

用户需要文件时，通过现有受信成果发布入口交付报告和标注副本。标注不得改原数据值；同一原件多个区域合并标注，不能污染未审范围。导出复用已保存结果，不重扫。

普通 Code 结果不必重新经过原生审查工具接纳才能使用或交付；需要兼容专用复核界面时才使用该界面的接纳适配。明确区分代码执行证据与独立方法验证。

## 修正
读取真实错误并修正代码/参数。写前版本或补丁匹配拒绝时，读取当前版本再提交新提案；真正结果未知的写入先对账，不盲目重放。已完成且可验证的计算直接复用。
